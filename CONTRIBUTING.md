# Contribution Guide

1. Open an issue (feature, bug or task). Describe the goal and acceptance criteria.
2. Assign an owner and select labels where possible.
3. Branch from updated `main` as `feat/<issue>-<slug>` or `fix/<issue>-<slug>`.
4. Prefer focused commits: `feat: add signup endpoint`, `fix: handle invalid token`.
5. Open a PR using the included template; reference `Closes #123` when appropriate.
6. Let CI run; investigate failures. Do not treat a skipped or absent check as passing.
7. Address review comments before requesting merge; obey branch protection.

Never paste secrets into issues, commits or PR comments.
